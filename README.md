# 🚀 CryptoZen

CryptoZen is a modern and responsive **cryptocurrency platform UI** designed to showcase crypto trading, digital assets, and wallet-related features.

## ✨ Features

* Responsive cryptocurrency landing page
* Modern dashboard UI
* Trading & wallet sections
* User profile, billing and authentication pages
* Blog and contact pages
* Responsive design and animations

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Bootstrap
* jQuery
* Font Awesome
* Owl Carousel

## 🚀 Getting Started

```bash
git clone https://github.com/YOUR-USERNAME/cryptozen.git
cd cryptozen
```

Open `index.html` in your browser to run the project.
